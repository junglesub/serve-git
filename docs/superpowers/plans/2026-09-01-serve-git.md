# serve-git Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build and verify a dependency-free npm CLI that exposes the current Git repository as a temporary read-only HTTPS remote and cleans up on exit.

**Architecture:** Keep the executable entry point thin and put reusable behavior in `src/core.mjs`. Use a static localhost HTTP server plus `git update-server-info`, and delegate internet tunneling to a temporary or existing `cloudflared` binary.

**Tech Stack:** Node.js ESM, Node built-in `node:test`, Git CLI, Cloudflare Quick Tunnel.

**Spec:** `docs/superpowers/specs/2026-09-01-serve-git-design.md`

## Global Constraints

- No third-party npm runtime dependencies.
- Read-only Git transport only.
- Bind HTTP only to `127.0.0.1`.
- All invocation-owned files live under one temporary directory and are removed on exit.
- Existing system `cloudflared` binaries are never deleted.
- Version 1 supports Linux and macOS x64/arm64 downloads.
